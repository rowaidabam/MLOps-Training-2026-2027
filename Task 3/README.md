# MLOps Training 2026–2027 — Task 3

## Overview

This project refactors a machine learning workflow from Jupyter notebooks into a production-style inference pipeline.

The project includes:

- Python inference modules
- Configuration management
- DVC for data and artifact versioning
- Logging and error handling
- Automated tests with pytest
- Saved preprocessing and model artifacts
