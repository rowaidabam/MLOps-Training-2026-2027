# MLOps Training 2026–2027

## Qafza Tech — Applied MLOps Training

This repository documents my hands-on learning journey through the **MLOps Engineering Training Program by Qafza Tech**.

The training focuses on applying MLOps practices to a real-world machine learning project using the **Olist Brazilian E-Commerce dataset**, with an emphasis on moving from data and experimentation toward reproducible and production-oriented ML systems.

---

## Project

### Olist Delivery Prediction

The main project focuses on predicting whether an e-commerce order will be delivered late or on time.

The dataset contains multiple interconnected tables from the Olist Brazilian E-Commerce marketplace, providing a practical environment for working with databases, data preparation, machine learning, and production workflows.

### Task 1 — OList Database

Database setup, SQL workflows, and connecting the Olist dataset with Python.

### Task 2 — From Tables to Notebooks

Data preparation, feature engineering, dataset splitting, and machine learning experimentation.

### Task 3 — From Notebooks to Production

Structuring the ML inference workflow into a reusable application with API, testing, configuration, and deployment-oriented components.
